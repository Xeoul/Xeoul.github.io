Sous Chef

A weekly meal planner that turns the recipes you pick into one shopping list.

Stack
JavaScript, HTML/CSS, Claude artifacts, localStorage
Links
Live ↗ Code ↗

The problem

Planning a week of meals and then writing the shopping list means adding up the same ingredients across several recipes, scaled to how many people you're cooking for, with some recipes in cups and others in grams. Sous Chef does that arithmetic for you.

What it does

  • Plan the week: tap recipes to plan them and set how many servings of each you're cooking.
  • One shopping list: ingredients scaled to your servings and merged across recipes, shown combined or grouped by recipe, and checked off as you shop.
  • US or metric units, switched with one tap.
  • Cook view: each planned recipe's scaled ingredients and step-by-step directions.
  • AI recipe import: search the web, paste a link or paste an ingredient list, and the recipe is sorted into fields for you.

How it's built

A single self-contained HTML page of plain JavaScript, with no build step and no dependencies. It was built as a Claude artifact: run inside Claude, recipes and the week's plan sync through the artifact's database, and recipe import uses AI parsing plus web search and fetch. Anywhere else, including the live demo, it saves to localStorage and works the same apart from the AI import.

A GitHub Actions workflow publishes the demo to GitHub Pages, with a small script that adds a few sample recipes the first time it opens with nothing saved.

Key decisions

Recipes as plain data

A recipe is a name, a base number of servings, a list of ingredients (amount, unit and name) and a list of steps. Scaling is one multiplication, and the combined list adds up ingredients whose name and unit match.

Converting through a base unit

Every weight is converted to grams and every volume to millilitres, then back into the most readable unit for the chosen system: under 15 ml shows as teaspoons, under 59 ml as tablespoons, then cups, quarts and gallons, and ounces become pounds at 16. So 48 teaspoons across three recipes shows up as 1 cup.

Update the list, don't rebuild it

Rebuilding the whole list on every tap replayed each row's entrance animation whenever you checked something off or changed a serving count. A keyed update patches the rows that are already there and only creates new ones, so only new items animate in.

No lost check-offs while syncing

Changes to the week are saved to the database after a short 350 ms pause. Until a change has been sent and acknowledged, any copy the database sends back is older than what's on screen, so it's held until the save settles. Otherwise it could briefly undo newer check-offs, and the next one would be built on that stale copy.

Current limits

AI import only works inside Claude, where the page can call a model and search the web; the standalone demo supports recipes you type in. Outside Claude, your recipes live in one browser.
